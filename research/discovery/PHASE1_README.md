## Layout

```text
procurement-intelligence/
  discovery/
    wbdisc/        reusable library (config, HTTP+retry+access log, raw store, normalisation, profiling, parsers)
    scripts/       s0* = extraction (raw samples), p0* = profiling / analysis, c01 = PoC cohort selection, b01 = Bronze inputs
    samples/       raw samples exactly as received + MANIFEST.jsonl (source, method, timestamp, sha256)
    data_cache/    git-ignored bulk public files (reproducible; checksums in data_cache/MANIFEST.jsonl)
    profiling/     computed statistics (JSON/CSV/MD) consumed by the reports
    schemas/       observed schemas (column names + observed value kinds)
    evidence/      access_log.jsonl (every HTTP request + status) and run logs
    reports/       the eight Phase 1 deliverables
    tests/         unit tests for normalisation / profiling / parsing utilities
  docs/decisions/  decision records pending approval
  docs/requirements/  assessment alignment report (the assessment itself is ./assessment.md)
  cohort/          2,000-project PoC cohort manifest, eligible pool, summary (generated by discovery/scripts/c01_select_poc_cohort.py)
  databricks_upload/  bronze_inputs/ (git-ignored, cohort-bounded raw extracts + _manifest/), notebooks/ (prepared, not run), BRONZE_INGESTION_GUIDE.md
```

## Reproduce

```bash
cd procurement-intelligence
python3 -m pip install -r requirements.txt
cp .env.example .env            # optional; defaults are fine
cd discovery
python3 -m pytest -q            # unit tests

# extraction (network; ~45 min; ~390 MB to data_cache, ~70 MB of PDFs)
python3 scripts/s01_contract_awards.py
python3 scripts/s02_projects.py          # v2 index (kept as evidence: frozen)
python3 scripts/s03_procnotices.py       # needs s01 (cluster selection uses DS00005)
python3 scripts/s02b_projects_v3.py      # needs s03 (cluster list)
python3 scripts/s04_documents.py         # v2 wds + core PDF sample
python3 scripts/s04b_documents_v3.py     # v3 wds + diversity PDFs
python3 scripts/s05_finance_ieg_indicators.py

# analysis (offline except p04/p05)
python3 scripts/p01_profile_structured.py
python3 scripts/p02_join_analysis.py
python3 scripts/p03_document_parsing.py
python3 scripts/p04_refresh_probe.py     # live API probes
python3 scripts/p05_procurement_plan_tables.py   # downloads ~40 procurement-plan PDFs
python3 scripts/p06_ml_feasibility.py
# assessment-alignment review (2026-10-21)
python3 scripts/p07_assessment_gap_probes.py     # small live probes + ~24 ISR .txt files + 1 guidance PDF
python3 scripts/p08_plan_reprocurement.py        # offline; needs p05 output
# PoC cohort (decision D-26, 2026-10-21)
python3 scripts/c01_select_poc_cohort.py         # offline; seeded; verifies input checksums -> ../cohort/
python3 scripts/b01_extract_bronze_inputs.py     # offline; byte-preserving cohort row selection -> ../databricks_upload/bronze_inputs/
```

Scripts are idempotent: an existing raw sample is never overwritten; delete it to re-extract.
Sampling is seeded (`WB_SAMPLE_SEED`), but the sources are live, so re-running on another date will
yield different populations. The MANIFEST checksums identify the exact files analysed.

## Data handling notes

* All sources are public World Bank Group data (CC BY 4.0 where stated). No authentication used.
* Raw values are never modified. Normalised values are always *derived* columns.
* Procurement-notice text and some project fields contain personal contact data (names, e-mails,
  phone numbers) published by borrowers/WB. The cluster extraction excluded contact fields via `fl`;
  `notice_text` still contains such data. Downstream use should minimise/strip it (see reports).
